Metric definitions

Wall time

Client-observed seconds for one completed request. Median is computed only inside one series and one prompt class; denominator is shown as successful/attempted measurements.

Prompt tok/s

Runtime-reported prompt evaluation throughput. Ollama and llama.cpp may define internal timing fields differently; it is shown per series and never pooled.

Decode tok/s

Runtime-reported generated-token throughput. Missing runtime counters remain blank, not zero.

Series key

A stable identity containing runtime, logical model and route. Different keys cannot share an average, axis or trend.

Reading the screen

  • Green observer status means the dashboard scan succeeded; it does not mean the benchmark completed.
  • Amber run status means work is in flight, not a performance result.
  • The current A/B is runtime + artifact, not a pure runtime effect.
